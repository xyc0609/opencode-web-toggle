# Screenshot provenance

`on.png`, `off.png`, `off-websearch.png`, and `on-websearch.png` are screenshots supplied by the user from OpenCode Desktop. The image pixel data was preserved, while EXIF and text metadata were removed for privacy. The first two show the green and red composer pills. The third shows a red pill and a web-search refusal. The fourth shows a green pill, a `Parallel Web Search` tool invocation, and a model answer. They contain no visible account name, API key, or absolute home-directory path.

These images document visible UI behavior only. They do not prove which plugin build was loaded or independently validate the web provider response. Earlier screenshots with private conversation content were excluded.
